## 09 — Software Quality Assurance
 
Software Quality is the degree to which a system meets specified requirements and user expectations; Quality Assurance is the set of planned, systematic activities ensuring quality is built into the process.
 
### Core Concepts
- **Quality Assurance (QA)**: process-oriented, preventive — ensures the *process* used produces quality output (e.g., process audits, standards compliance).
- **Quality Control (QC)**: product-oriented, detective — verifies the *product* meets requirements (e.g., testing, inspections).
- **Software Quality Management**: overarching set of activities (QA + QC + process improvement) to achieve and sustain quality across projects.
### Comparison: QA vs QC
| Aspect | Quality Assurance | Quality Control |
|---|---|---|
| Focus | Process | Product |
| Approach | Preventive | Detective/corrective |
| Example | Process audits, standards | Testing, code review |
 
### Software Quality Attributes
- Correctness, Reliability, Efficiency, Integrity, Usability, Maintainability, Flexibility, Testability, Portability, Reusability, Interoperability (McCall-style quality factors, commonly cited in this context).
### Software Quality Standards
- **ISO 9000**: family of generic quality management standards; certifies that an organization's *process* (not the product directly) meets defined quality management criteria — applicable across industries, adapted to software via guidance standards.
### Process Improvement
- **Software Process Assessment**: evaluating an organization's software process against a reference model to identify strengths/weaknesses.
- **SEI Capability Maturity Model (CMM)**: a 5-level framework (from SEI, Carnegie Mellon) describing the maturity of an organization's software process.
### CMM Levels
| Level | Name | Characteristic |
|---|---|---|
| 1 | Initial | Ad hoc, chaotic; success depends on individual effort |
| 2 | Repeatable | Basic project management processes established; past successes repeatable |
| 3 | Defined | Process standardized, documented, and integrated org-wide |
| 4 | Managed | Process and product quality measured quantitatively |
| 5 | Optimizing | Continuous process improvement via quantitative feedback |
 
### Practical Takeaway
- QA prevents defects by improving process; QC catches defects already in the product — both are needed.
- CMM level indicates process predictability, not necessarily product quality directly — useful in vendor selection/outsourcing decisions.
- ISO 9000 certification signals process discipline to external stakeholders/clients, especially in contract-based development.
### Quick Reference
| Term | Meaning |
|---|---|
| QA | Preventive, process-focused |
